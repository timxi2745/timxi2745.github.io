Vehicle Motion Data Analysis

Experimental Data Collection & MATLAB Analysis

Overview

This project involved collecting motion data from a vehicle and using MATLAB to analyze its displacement, velocity, and acceleration.

Data Collection

Experimental data was collected during vehicle motion and then processed for further analysis.

MATLAB Analysis

MATLAB was used to process the collected data and generate displacement, velocity, and acceleration results. The data was visualized to examine the vehicle's motion over time.

Results

The project provided practical experience with experimental data, numerical analysis, and using MATLAB to interpret real-world mechanical motion.
